# Capturas

Colocá acá las capturas de pantalla que se muestran en el README principal, con estos nombres exactos:

| Archivo | Pantalla |
| --- | --- |
| `escanear.png` | Escanear un ticket (con el OCR ya cargando los datos) |
| `comprobantes.png` | Listado de comprobantes |
| `reportes.png` | Reportes / totales |

Formato recomendado: **PNG**, ancho ~1200–1600 px, sin datos sensibles reales.
